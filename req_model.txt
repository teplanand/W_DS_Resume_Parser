🧠 Core Components
The model includes the following pipeline components:
tok2vec: Token-to-vector transformation
tagger: Part-of-speech tagging
parser: Dependency parsing
senter: Sentence segmentation
attribute_ruler: Rule-based attribute assignment
lemmatizer: Lemmatization
ner: Named Entity Recognition
